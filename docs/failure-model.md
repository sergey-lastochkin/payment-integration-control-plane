# Сценарии сбоев

Сохранённый локальный прогон: [summary.json](../failure_lab/runs/local-2026-08-10-01/summary.json). Каждая строка создана `failure_lab/run.py`, а не заполнена вручную.

| Сбой | Поведение модели | Граница доказательства |
|---|---|---|
| Повторное создание или HTTP-запрос | Повторно используется одна операция | Локальный SQLite и file adapter |
| Ответ отправителя потерян после принятия | Операция не переоткрывается; пришедший статус сохраняет `accepted` | Локальный адаптер возвращает статус до TimeoutError |
| Повторный статус | `event_id` не создаёт вторую запись аудита | Локальная модель обработки статуса |
| Повторная выписка | Строка помечается replay | Локальный matcher |
| Равные кандидаты | `manual_check`, без автоматического выбора | Локальный matcher |
| Нет маршрута, нет авторизации | Остаётся `sending`, нужна сверка перед повтором | Исключение в локальном адаптере |
| Повреждённый конверт | SHA-256 не совпадает, конверт отклоняется | Локальный файловый адаптер |
| Ручное решение | Terminal status с источником `manual_resolution` | Локальная модель аудита |

Тест не подтверждает поведение конкретного банка. Для тестового банка требуется отдельная карта ошибок: какие ответы гарантируют отсутствие приёма, а какие оставляют исход неопределённым.
